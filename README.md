# 🧮 Calculator

A simple and user-friendly calculator built using **HTML, CSS, and JavaScript**.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Clear button
- Delete button
- Responsive design
- Easy-to-use interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Use

1. Open the calculator in your browser.
2. Enter numbers using the calculator buttons.
3. Choose an arithmetic operation.
4. Press the equals (=) button to see the result.
5. Use the Clear button to reset the calculator.
